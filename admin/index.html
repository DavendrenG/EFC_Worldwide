One-time

Setup

Seed the database

Loads the real EFC events, fighters and news into Firestore so the app has content from the first launch. Safe to run more than once — it writes to fixed document ids rather than creating duplicates.

Firebase config goes in firebaseConfig at the bottom of this file. Project settings → General → Your apps → Web app.

Staff accounts

Create each EFC user under Authentication → Users, then mark them staff by running this once per account with the Admin SDK. The security rules below check that claim.

const { getAuth } = require('firebase-admin/auth');
await getAuth().setCustomUserClaims(uid, { efcStaff: true });

Firestore rules

Deploy with firebase deploy --only firestore:rules. Without these anyone can write to your collections.

rules_version = '2';
service cloud.firestore {
  match /databases/{db}/documents {
    match /{col}/{id} {
      allow read: if true;
      allow write: if request.auth != null
                   && request.auth.token.efcStaff == true;
    }
  }
}

Push relay

Browsers cannot send FCM directly — the server key would be readable in view-source. Deploy the functions in functions/index.js. Requires the Blaze plan.

cd functions && npm install
firebase deploy --only functions
